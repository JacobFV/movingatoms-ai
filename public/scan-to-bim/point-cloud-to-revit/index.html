How to convert a point cloud to Revit

There are two ways to turn a point cloud into a Revit model: model it yourself against the linked cloud, or have it converted for you. This guide walks through both.

Updated October 20, 2026By the Moving Atoms team

1. Prepare the point cloud

Register the individual scans into one cloud, remove noise and moving objects (people, vehicles), and check the coordinate system and units. Most teams do this in the scanner vendor's software or in Autodesk ReCap Pro, then save an RCP/RCS project that Revit can link. Keep the full-resolution export (for example E57) as well.

2. Link it into Revit

In Revit, use Insert › Point Cloud to link the RCP or RCS, choose the positioning (origin to origin, or shared coordinates if your project uses them), and create views and section boxes for each level or zone so the cloud stays responsive.

3. Model against the cloud

  • Set levels and grids from the cloud first.
  • Model walls, floors and roofs, then columns and beams.
  • Add doors, windows and openings.
  • Model MEP: ducts, pipes, cable trays and equipment. This is usually the slowest part.
  • Check deviations against the cloud as you go, to the accuracy your brief requires.

Decide the LOD before you start: it sets how much of each element you model.

4. Tools that speed up manual modeling

Plug-ins and software can extract parts of the model for you, though an operator still drives and checks the result:

  • Autodesk ReCap Pro 2026 can create segmented meshes that a Revit plug-in places as families.
  • FARO As-Built for Revit adds point cloud modeling and accuracy tools inside Revit.
  • ClearEdge3D EdgeWise extracts walls, pipes and conduit to Revit families.

Frequently asked questions

Can Revit open a point cloud directly?

Revit links point clouds as RCP or RCS projects, usually created in Autodesk ReCap. Other formats such as E57 or LAS are converted to RCP/RCS first.

Can a point cloud be converted to Revit automatically?

Tools such as ReCap Pro 2026, FARO As-Built and EdgeWise automate parts of the modeling, but an operator still drives the work. A service such as Moving Atoms delivers the finished, separated Revit model within 48 hours.

How long does it take to model a point cloud in Revit?

Manually, it scales with the area, the LOD and the number of elements, and larger sites usually take weeks. Moving Atoms delivers within 48 hours.
